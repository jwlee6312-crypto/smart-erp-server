# 영업활동관리 (HSAA) 실적 매트릭스 디자인 고도화 및 컬럼 균등화 계획

HSAA 모듈의 모든 현황(S) 화면 상단에 위치한 실적 매트릭스(Matrix Table)의 디자인을 표준화하고, 데이터 컬럼의 너비를 완벽하게 균등 배분하여 시각적 완성도를 높입니다.

## 1. 매트릭스 테이블 표준 디자인 (HSAA310S 기준)

- **테이블 레이아웃**: `table-layout: fixed`를 적용하여 컬럼 너비를 엄격히 제어.
- **헤더 색상**:
    - 기본 헤더: `#f1f5f9` (Light Gray/Blue) 기반의 부드러운 톤 유지.
    - 합계 컬럼: `#374151` (Dark Gray) 배경에 흰색 글자로 강조.
- **폰트 및 정렬**:
    - 헤더 폰트 크기 `11px`, 데이터 폰트 크기 `12px` (Pretendard).
    - 수치 데이터는 중앙 정렬을 원칙으로 하되, 금액인 경우 우측 정렬.

## 2. 컬럼 균등 배분 전략

각 화면의 데이터 특성에 맞춰 가로 폭을 퍼센트(%) 또는 고정 px로 균등하게 나눕니다.

| 대상 화면 | 데이터 컬럼 구성 | 배분 전략 |
| :--- | :--- | :--- |
| **HSAA310S/320S** | 12개월 (기업/개인 각 2열) + 합계 | 각 월별 그룹 너비를 동일하게 고정 (80px), 내부 40px 배분 |
| **HSAA340S** | 8개 영업 단계 (고객선정 ~ 포기) | 모든 단계 컬럼 너비를 가로폭에 맞춰 균등 배분 (약 10~12%) |
| **HSAA370S** | 성공/실패/보류 (각 건수/비율) | 분석 그룹별 너비 균등화 (그룹당 약 25~30%) |
| **HSAA380S/390S** | 당기 실적(8~9개) + 차기 계획 | 실적 영역과 계획 영역의 컬럼 폭을 시각적으로 균일하게 조정 |
| **HSAA410S** | 유입/진행/유출 (8~9개 단계) | 가로 스크롤을 최소화하며 데이터 칸을 촘촘하고 균등하게 배치 |

## 3. 세부 스타일 보정

- **Sticky Column**: '부서명', '담당자' 고정 컬럼의 배경색과 구분선을 더 명확하게 처리 (`border-right: 2px solid #dee2e6`).
- **Hover/Selected**: 로우 마우스 오버 시 `#f8fafc` 배경색 적용으로 가독성 향상.
- **Border**: `border-collapse: separate`와 `border-spacing: 0`을 사용하여 세련된 격자 디자인 구현.
