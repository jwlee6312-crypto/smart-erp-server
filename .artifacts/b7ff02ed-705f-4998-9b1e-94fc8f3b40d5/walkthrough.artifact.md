# 모바일 시스템(앱/백엔드) 통합 및 로컬 환경 정비 완료 보고

기존에 분산되어 있던 모바일 앱과 백엔드 프로젝트를 메인 ERP 프로젝트 구조로 통합하고, 로컬 MSSQL(`SMARTDB`)에 연결할 수 있는 기반 설정을 완료했습니다.

## 주요 변경 사항

### 1. 프로젝트 구조 재배치 (Monorepo)
- **`erp-mobile-backend`**: 기존 `erp-mobileback` 폴더의 이름을 변경하고 루트 프로젝트의 하위 모듈로 편입했습니다.
- **`erp-mobile-app`**: 안드로이드 네이티브 앱 프로젝트를 루트 프로젝트의 하위 모듈로 편입했습니다.

### 2. Gradle 통합 (`settings.gradle`)
- 루트 프로젝트의 `settings.gradle`에 `erp-mobile-backend`와 `erp-mobile-app`을 추가했습니다.
- 이제 안드로이드 스튜디오에서 **File -> Sync Project with Gradle Files**를 실행하면 모든 모듈을 한 번에 관리할 수 있습니다.

### 3. 모바일 백엔드 로컬 최적화 (`env.properties`)
- **포트 번호**: 메인 백엔드(8080/8081)와 충돌하지 않도록 **`8082`** 포트로 고정했습니다.
- **DB 연결**: 도커가 아닌 노트북 로컬의 **MSSQL(`SMARTDB`)**에 바로 접속하도록 접속 정보(localhost:1433)를 설정했습니다.
- **파일 경로**: 윈도우 물리 경로(`D:/...`)를 사용하여 업로드/다운로드 기능이 정상 작동하게 했습니다.

## 사용자 수행 안내

> [!IMPORTANT]
> **프로젝트 새로고침**: 안드로이드 스튜디오 상단 메뉴에서 **File -> Sync Project with Gradle Files**를 반드시 실행해 주세요. 모든 모듈이 프로젝트 창에 활성화됩니다.

> [!TIP]
> **XML 쿼리 수정**: 이제 `erp-mobile-backend` 모듈 내부의 XML 매퍼 파일들을 열어, 기존 MySQL 문법으로 작성된 쿼리들을 사용자님의 계획에 맞춰 MSSQL 문법으로 수정해 나가시면 됩니다.

이제 하나의 안드로이드 스튜디오 화면에서 웹 ERP와 모바일 시스템 전체를 편리하게 개발하실 수 있습니다.
